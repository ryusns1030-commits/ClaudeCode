# 映像演出・シーン構成（第2段階・実装版）

- 仕様：1080×1920／30fps／1322フレーム（44.07秒）／H.264 yuv420p BT.709 TVレンジ／AAC 48kHz ステレオ
- 実装：`articles/n75be77a4bb85-chatgpt-sales-email/video/`（Remotion）。演出はすべて `useCurrentFrame`・`interpolate`・`spring`・`Sequence` で動かし、CSSアニメーション・`Math.random()`・実時刻は使っていない（光の粒やまばたきは、フレーム番号から計算する固定ハッシュで決める）。
- タイミング：`deliverables/timeline.json` の `events`（発話の瞬間のフレーム）に合わせた。効果音も同じフレームに置いている。
- セーフエリア：上200px・下330px・右132pxを避ける。カードは x=72〜948、y=330〜1100。字幕帯は y=1340〜1590。キャラクターの定位置は x≈754〜946、y≈1040〜1300 で、カードや字幕と重ならない位置にしている。
- 配色：ネイビー・ブルー・ホワイト・シアン。珊瑚色は「そのまま送信」「待って！」「未確認」だけに使う。
- 再利用した共通資産：`src/character/CharacterSVG`（ココナビ）、`src/anim`、`src/theme`（フォント・色）、`src/components/common` の `Phrases`（BudouX）と `Card`、`src/components/icons`。

共通の演出：
- シーン切り替えは8フレームのクロスフェード（上下移動とぼかしつき）。
- 上部に進行バーとシーン番号のチップ。右上に小さく「Co.Co.Motivate」（エンディングでは消す）。
- 字幕はナレーションに同期し、BudouX と `text-wrap: balance` で改行する。L02・L07 は改行位置を指定した。強調語は `script.json` の `emphasis` で色を付けている（シアン。「未確認」だけ珊瑚色）。
- 口パクは、audio_query の子音長・母音長から作ったフレームごとの母音列（`timeline.mouth`）で切り替える。

音：
- BGM：既存と同じ曲調（104BPMのローファイ）を numpy で合成。ナレーション中は約−7dBダッキングする。
- 効果音：ウーッシュ、ポップ、ティック、タイピング、スタンプ、チャイム、インパクトを numpy で合成（外部素材なし）。
- 音量：−15 LUFS に正規化。True Peak は −1.5 dBFS（MP4の実測）。
