# 完成台本（第1段階・v2）

- 作品：「ChatGPTの英訳、そのまま送らないで｜頼み方3つ＋送る前の5チェック」
- 原作：note「ChatGPTで海外向け営業メールを英訳。2024年に試したAI文章作成の実体験」（2026-11-12）
- 型：**A 悩み解決型**（悩み → 実例 → 解決策 → 注意点 → 行動）

- 主題（1つ）：**AIで英訳した営業メールを、安全に使える状態にする方法**
- ナレーション：VOICEVOX:春日部つむぎ（ノーマル）／speedScale 1.25・intonationScale 1.15・48kHz
- 推定尺：約43.5秒。時刻は推定（約7.8モーラ/秒）で、第2段階で実測値に置き換える。

## 事実の扱い（要点）
- 実体験として語るのは、英訳を依頼したこと、件名が相手のメリット型になったこと、別案にお詫びの表現が入ったことだけ（F1・F5・F7）。
- 「送信・返信は未確認」を明言する（U1・U2）。成約や返信率など、成果を示す言葉は使わない。
- 頼み方3つとチェック5項目は、原作の提案（P3・P4）をそのまま使う。画面にも「再現例」であることを注記する。
- 英文メールの本文は創作しない。伏せ字のイメージとして表示する。
- 営業先の業種・名称は出さない。
