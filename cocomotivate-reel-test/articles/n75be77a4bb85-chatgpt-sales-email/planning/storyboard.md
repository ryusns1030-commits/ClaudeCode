# 映像演出・シーン構成

共通仕様：1080×1920／30fps／Remotion。既存の `src/character/`（Navigator）、`components/common.tsx`、`theme.ts`、BudouXによる字幕を再利用する。
- セーフエリア：上部200pxと下部330pxには重要な情報を置かない。右端120pxには数字・字幕・顔を置かない。
- 字幕帯：y=1340〜1590、54px Black、最大2行。
- 配色：ネイビー、ブルー、ホワイト、シアン。珊瑚色は「そのまま送信」「未確認」の2か所だけに使う。

キャラクター（既存デザイン）：白いスクワークル型の頭、ネイビーのバイザー、発光する目と口、浮遊する手、アンテナ、胸のグラフエンブレム。全編を1つのレイヤーに置き、キーフレームで移動させる。字幕帯とカードには重ねない。

## シーン1：フック（0〜約6秒）
| 要素 | 演出 |
|---|---|
| 0フレーム目 | すでに画面に表示されている：オリジナルのAIチャット風UI（実在サービスのUIは模倣しない）に、英文の下書き（伏せ字の行）と珊瑚色の「Send」ボタン。上部ラベル「ChatGPTで英訳したあと…」、予告チップ「最後に『送る前の5チェック』」 |
| `sendButtonHover`（ソノママ） | カーソルがボタンへスライドし、ボタンが少し拡大。ティック音 |
| `waitStamp`（オクッテ） | キャラクターが右下から「驚き」の表情で飛び込み、手のひらで制止するポーズ。「待って！」スタンプ。スタンプ音 |
| `promise3`／`promise5` | 画面がスライドし、2枚のカード「頼み方 3」「チェック 5」がポップで出る。数字は0からカウントアップ |
| キャラクター | 驚き → 笑顔。カードの左下に移動する |

## シーン2：実体験（約6〜19秒）
| 要素 | 演出 |
|---|---|
| `dateChip` | 日付チップ「2024.10.08 の会話記録」がウーッシュとともにスライドイン |
| `chatTyping` | チャットUI：ユーザー側の吹き出し「Instagram運用代行の営業メール → 自然なアメリカ英語に」がタイピング表示。AI側の返答は、伏せ字の英文行が順番に伸びる。注記「※英文はイメージです（実際の文面は非公開）」 |
| `subjectCard` | 件名比較カード：上段「よくある件名：サービスのご案内」（グレーで取り消し線。当時の実際の件名ではなく、原作が比較に使った一般例であることを「よくある」で示す）、下段「相手のメリットを伝える件名」（シアン、ズームイン） |
| `meritHighlight` | 「相手のメリット」にシアンのグロー。チャイム音 |
| `apologyCard` | 小さなカード「別案：突然の連絡へのお詫びも」。キャラクターが指差す |
| `unconfirmedStamp` | 画面中央にスタンプ「送信・返信・成約：未確認」（珊瑚色）。インパクト音。キャラクターは「真剣」の表情 |
| `draftLabel` | 英文カードの右上に「DRAFT／下書き」の札が付く。スタンプ音 |
| キャラクター | 考えるポーズ → 指差し → 真剣 |

## シーン3：頼み方3つ（約19〜28秒）
| 要素 | 演出 |
|---|---|
| 背景 | プロンプトカード（原作の再現用プロンプト全文）が下からスライドイン。注記「※記事用に整理した再現例です（当時の原文ではありません）」 |
| `cond1`／`cond2`／`cond3` | 該当行（読み手と場面／実績を追加しない／日本語で説明）が順番にシアンでハイライトされ、左に①②③バッジがポップで出る。ハイライト中の行は画面をわずかにズーム |
| キャラクター | カードの左上で手振り → 各条件を指差す |
| 進行 | 上部の進行バーに「頼み方 1/3 → 3/3」 |

## シーン4：送る前の5チェック（約28〜33秒）
| 要素 | 演出 |
|---|---|
| `checklistOpen` | クロスフェードでチェックリストカードに切り替える |
| `checkItem` ×5 | 0.32秒おきに5項目が上から登場し、チェック印が付く。ティック音 |
| ヒント | 余韻の間に下部へ「保存して、送信前に見返そう」 |
| キャラクター | 余韻の間はカードの外（左下）で頷く。項目を隠さない |

## シーン5：結論（約33〜40秒）
| 要素 | 演出 |
|---|---|
| `splitCompare` | 左右分割の比較図：「文章の完成 ✔」と「営業の成果 ？」。間に「≠」をズームで表示 |
| `humanJudge` | 「AI＝出発点 → 人＝判断」の矢印。チャイム音。キャラクターは笑顔で胸のエンブレムを光らせる |
| 整理 | BGMのドラムを抜き、背景の動きも止める。メッセージだけを見せる |

## シーン6：CTA（約40〜43.5秒）
| 要素 | 演出 |
|---|---|
| `saveIcon` | 保存アイコン（ブックマーク）がポップで出る。キャラクターが指差す |
| 画面テキスト | 「成功も限界も、実体験から。AI×仕事のリアルを発信中」／Co.Co.Motivate／VOICEVOX:春日部つむぎ |
| キャラクター | 手振りをしながら退場の準備をし、最後のフレームでは定位置に戻る（ループ再生を考慮） |

## 音
| 種類 | 内容 |
|---|---|
| BGM | 既存のPython＋numpyによるローファイ調を再利用。ナレーション中は約−7dBダッキング。結論シーンではドラムを抜く |
| 効果音 | tick, stamp, pop, whoosh, typing, chime, impact を cue に同期させる（`script.json` の `cues`） |
| 音量目標 | True Peak −1 dBFS以下（前回と同じく −2 dBFS 目安）、約 −17 LUFS |

## シーン切り替え
8フレームのクロスフェード＋わずかな上下移動とぼかし（既存の方式）。キャラクターはシーンをまたいで連続して移動する。
