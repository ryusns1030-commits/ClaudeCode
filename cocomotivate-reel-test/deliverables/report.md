## 2. 制作工程と、実際にできたこと

1. **環境確認**：Node 22.23、npm 10.9、ffmpeg、Docker 29、Python 3.13、Chromium Headless Shell（プリインストール）、CPU 4コア。
2. **原作記事**：`note.com` がこのクラウド環境のネットワーク許可外（DNS解決不可）だったため、**記事本文は読めていない**。依頼文の「原作の重要情報」を原作として扱い、事実はそこから一切足していない。
3. **プロジェクト構築**：新規フォルダ `cocomotivate-reel-test/` に独立したプロジェクトを作成。既存ファイルは変更していない。Remotion 4.0.543（npm 最新）、React 19、TypeScript。Remotion公式のエージェントスキル（`remotion-dev/skills`）を取得し、書き方（`interpolate`／`spring`／`Sequence`、CSSアニメーション禁止、`@remotion/fonts`、`@remotion/media` の Audio）を参照した。
4. **台本**：初稿は58秒だったため、話速と表現を詰めて約45秒の発話に収めた。ただし事実をすべて残したため、総尺は「間」を含めて **54.7秒**（目安の30〜45秒を超過。下の「制約」を参照）。
5. **キャラクター**：オリジナルのAIナビゲーター「ココナビ」をSVGとReactで新規に設計。白いスクワークル型の頭、ネイビーのバイザー画面、発光する目と口、アンテナ、浮遊する手、胸の上向きグラフのエンブレムで構成。配色はネイビー・ブルー・ホワイト中心。
   - 実装したアニメーション：**まばたき**（2.6〜4秒間隔の決定論的な乱数、6フレーム）、**口パク**、**手振り**、**体の上下運動（浮遊）と影の伸縮**、**驚き・考える・笑顔・真剣の表情**（切り替え時にスクワッシュ）、**指差し・バンザイ**、**画面への登場と退出**（シーン5の終わりに下へ退場し、シーン6で再登場）。
6. **AI音声**：ローカルの **VOICEVOX Engine 0.26.1（Docker, CPU）** で合成。Docker Hub がレート制限（429）を返したため、Google の公開ミラー `mirror.gcr.io` から同じイメージを取得した。話者は **春日部つむぎ（ノーマル）**。
   - 規約の確認（エンジンAPI `/speaker_info` と `/engine_manifest` で取得）：「VOICEVOX:春日部つむぎ」とクレジットを記載すれば商用・非商用で利用可。エンジン本体も商用利用可で、VOICEVOX を使ったことがわかるクレジットが必要。→ 動画の最後と台本に **「VOICEVOX:春日部つむぎ」** と表記した。
   - No.7 など、商用利用に事前確認が必要な話者は選ばなかった。
   - 数字の読みは VOICEVOX が返す読み（kana）で確認した（例：3433 → サンゼンヨンヒャクサンジュウサン）。読み間違いを避けるため、「20台」は「にじゅうだい」、「2択」は「にたく」、「ChatGPT」は「チャットジーピーティー」と、TTSには読みを直接入力した。
7. **字幕と口パクの同期**：1行ずつ音声を合成し、**WAVの実測の長さ**から字幕の表示フレームを算出。口パクは VOICEVOX の `audio_query` が返すモーラごとの子音長・母音長から、**フレームごとの母音（あ・い・う・え・お・ん・無音）**を求め、口の形を切り替えている（音素レベルの同期）。演出キュー（「20台」の表示、チップやカードの出現、「未確認」スタンプなど）も、読みの中のキーワード位置から自動で算出している。
8. **BGM・効果音**：外部素材は使わず、numpy で**手続き的に合成したオリジナル**（104BPMのローファイ調：エレピ風コード、ベース、アルペジオ、キック／スネア／ハイハット）。ナレーション中はサイドチェインで約 −7dB 下げる。シーン5ではドラムとアルペジオを抜いて静かにしている。効果音（ウーッシュ、ポップ、カウントのティック、ドスン、スタンプ、タイピング、チャイム）も同様に合成。
9. **レンダリング**：`remotion render` で1回あたり約1分47秒（4並列）。

## 3. 品質検査（実施した項目のみ記載）

完成した `reel.mp4` そのものに対して ffprobe／ffmpeg で検査した。

| 項目 | 方法 | 結果 |
|---|---|---|
| 解像度・fps・フレーム数 | ffprobe | 1080×1920, 30/1, 1642フレーム ✅ |
| コーデック | ffprobe | H.264 High, yuv420p, tv range, BT.709 ／ AAC-LC 48kHz 2ch ✅ |
| 尺 | ffprobe | 映像 54.733秒・音声 54.741秒（ほぼ一致）✅ |
| 黒画面 | blackdetect (0.1秒以上, pix_th=0.05) | 0件 ✅ |

| デコードエラー | `ffmpeg -v error -f null` | なし ✅ |
| 音声のずれ | MP4の音声とミックス元WAVの相互相関 | オフセット 0ms ✅ |
| 字幕どうしの重なり | タイムラインで判定 | 0件 ✅ |
| 表示の目視検査 | MP4から計約25時点のフレームを抽出（`qc/`） | 文字切れ・はみ出しなし。下記の問題を修正済み ✅ |
| 口パク | 発話中の顔を3フレームおきに10枚並べて目視 | 母音に応じて口の形が変わること、手振りとまばたきを確認 ✅ |

検査で見つけて修正した問題
1. シーン1：キャラクターが閲覧数カードのバーに重なっていた → カードとキャラクターの位置・大きさを調整。
2. シーン2：「※画面はイメージです」の注記にキャラクターが重なっていた → キャラクターを右側へ移動。
3. シーン3：「改善策を検討中…」の表示が「運用目的」チップに重なっていた → チャット枠を拡大。チップの出現に合わせて吹き出しが伸びるように変更。
4. 字幕：文節の途中で改行されていた → BudouX と `text-wrap: balance` で、文節単位のバランスのよい2行に。
5. 口パク：モーラの間で口が一瞬「にっこり」に戻ってちらついていた → 発話中の短い隙間は小さく閉じた口形を保つように変更。
6. エンディング：前半カードの消え残りが決め台詞に重なっていた → 消えるタイミングを字幕の開始に合わせた。
7. 音声：True Peak +0.3 dBFS → −1.8 dBFS。色範囲：yuvj420p（フルレンジ）→ yuv420p（TVレンジ, BT.709）。

**検査していない項目（未検証）**
- **人の耳による試聴**：制作AIは音声を聴けないため、声の自然さ、アクセント、BGMの聴感バランスは**未検証**。数値（ラウドネス、ピーク、無音区間）と読み（kana）での確認にとどまる。特に「にじゅうだい」のアクセントや、合成BGMの音質は試聴で確認してほしい。
- **実機での再生**：Instagramへのアップロード、スマートフォン実機、VS Code での再生は試していない。
- 全1642フレームの目視はしておらず、代表時点の抽出による検査。

## 4. できなかったこと・制約

- **原作記事を読み込めていない**（note.com がネットワーク許可外）。依頼文の要約情報だけで制作した。記事にある細かな表現や追加の事実は反映されていない。
- **尺が54.7秒**で、目安の30〜45秒を超えた。事実をすべて残し、「20台」や「未確認」の見せ場に1秒前後の余韻を取ったため。短くするなら、シーン2の「リールとは別の課題」を削る、話速を1.35に上げる、といった方法がある（`scripts/script.json` を書き換えて再実行すればよい）。

## 5. 使用技術

- Remotion 4.0.543（`remotion`、`@remotion/cli`、`@remotion/fonts`、`@remotion/media`）、React 19、TypeScript 5、Node.js 22
- アニメーションはすべて `useCurrentFrame` ／ `interpolate` ／ `spring` ／ `Sequence` によるフレーム基準（CSSアニメーションや時刻依存の処理は不使用、乱数も決定論的なハッシュ）
- BudouX（日本語の文節改行）
- VOICEVOX Engine 0.26.1（Docker, ローカル）
- Python 3.13 ＋ numpy（タイムライン生成、BGM・効果音の合成とミックス）
- ffmpeg／ffprobe（検査）、Playwright（SVGの確認）

## 6. 再現手順

```bash
cd cocomotivate-reel-test
npm install
python3 -m venv .venv && .venv/bin/pip install numpy
docker run -d -p 50021:50021 mirror.gcr.io/voicevox/voicevox_engine:cpu-latest
.venv/bin/python scripts/tts.py          # 音声合成 → build/voice/
.venv/bin/python scripts/make_audio.py   # タイムライン + BGM/SE ミックス → src/timeline.json, public/audio/master.wav
npx remotion render Reel out/reel.mp4    # 動画
npx remotion still Cover out/thumbnail.png
npx tsx scripts/export_character.tsx     # character.svg
npx remotion studio                      # プレビュー（ブラウザ）
```
`remotion.config.ts` はプリインストールの Chrome Headless Shell のパスを指定している。別の環境では、この行を削除すれば Remotion が自動でブラウザを取得する。

## 7. 次回改善できる点

1. 原作記事に直接アクセスできる環境（note.com を許可）で、本文に基づいて事実確認する。
2. 人の耳で試聴し、アクセント句（VOICEVOX の `accent_phrases`）を手で調整する。

6. 字幕の単語単位ハイライト（カラオケ式）。モーラのタイミングは既にあるので実装しやすい。
