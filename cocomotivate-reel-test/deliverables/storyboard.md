# シーン構成（v2）

1080×1920 / 30fps / 1707フレーム（56.9秒）。演出キューは、ナレーションのモーラ（音の単位）タイミングから自動で算出している。

## v2の方針
- **最初の2秒で掴む**：
  - 0フレーム目から「ストーリーズ閲覧数 ？」のカードと「最後にAI活用のコツを3つ紹介します」の予告が表示されている（フェードインなし）。
  - 1.6秒の発話「にじゅうだい」と同時に、「20台」がカードの赤いフラッシュ・揺れ・ドスン音とともに着地する。
  - 落差の強い数字を先に出し、比較対象のフォロワー数を後に出す順番にした。
- **持ち帰れる価値**：「AI活用のコツ3つ」のシーンを新設し、保存を呼びかけて終える。
- **オチ**：「私たちも、AIで考え、数字で確かめる運用を実践していきます」で、Co.Co.Motivateの今後の姿勢を示す。
- **空白を作らない**：各シーンの最初の要素はシーン開始直後から表示する。
