# シーン構成（ストーリーボード）

1080×1920 / 30fps / 1642フレーム（54.73秒）。演出キューは、ナレーションのモーラ（音の単位）タイミングから自動で算出している。たとえば「20台」は「にじゅうだい」の最初のモーラが鳴った瞬間に表示される。

共通レイヤー
- 背景：ネイビーのグラデーション、ゆっくり流れるグリッド、上昇する光の粒、漂う光のボケ。シーン5だけ少し暗くして空気を締める。
- 上部：ストーリーズ風の6分割進行バー（y=196）と、右上の「Co.Co.Motivate」ウォーターマーク。
- 字幕帯：y=1340〜1590。Instagram下部のUIを避けた位置。54px Black。BudouXで文節ごとに改行し、数字・固有名詞はシアン色で強調。
- ナビゲーター「ココナビ」：全編に登場し続けるレイヤー。キーフレームで移動・拡大し、表情とポーズを切り替える。
