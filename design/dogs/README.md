## 制作手順（STEP 2 で確立）

1. Canva の generate-image で、正方形・白背景の normal を生成します。
   - 2 犬種目以降は、001 normal を画風の参照画像にします。
2. happy は、その犬種の normal を参照画像にして生成します（同じ子に見えるようにするため）。
3. Canva の remove-background で背景を透過します。
4. ファイル 01 の該当ページに配置します。
   - ページは 1080×1080 で、背景色は白です。
   - 書き出し時は透過背景を指定します。
5. 犬の外接矩形を 864px（余白 8%）に収め、中央に配置します。
   - 拡大は resize で行います。
   - 縮小は resize のあと crop_media で画像枠を合わせます（枠だけが縮んで画像が切れるのを防ぐため）。
6. PNG で書き出します（transparent_background、1024×1024、可逆圧縮）。
   - ページ番号から `dog_{ID}_{pose}.png` に名前を変更します。
   - (page+1)/2 = ID、奇数ページ = normal、偶数ページ = happy です。
7. スクリプトで確認します。
   - RGBA であること、四隅のα = 0、余白の左右対称。
8. 目視で確認します。
   - アプリの背景色 #FBF7F0 の上で、200px・48px・32px の縮小を見ます（`prototype_sheet.png`）。

### プロンプトの型（normal）

> 犬種別イラスト素材：{犬種名}（{外見的特徴}）。ポーズ normal：座っていて、正面〜少し斜め向き、落ち着いた表情。オリジナルで、かわいく、犬種が判別できるイラスト。やさしいフラットなイラスト、細めの茶系の線、やわらかい陰影、落ち着いた彩度、大人も使いやすい温かいテイスト。全身が入り、周囲に均等な余白。背景は無地の白一色。文字・ロゴなし、光沢のある3D表現なし、足や耳の数が正しいこと。

### プロンプトの型（happy。参照画像はその犬種の normal）

> 参照画像と同じ犬（同じ{犬種名}、同じ毛色・線・塗り・デフォルメ度）で、ポーズ happy：口を開けてにっこり笑い、少し動きのある楽しそうなポーズ（片方の前足を少し上げる、しっぽを振る）。全身が入り、周囲に均等な余白。背景は無地の白一色。文字・ロゴなし、光沢のある3D表現なし、足や耳の数が正しいこと。
