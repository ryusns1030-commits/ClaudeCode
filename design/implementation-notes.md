## 2. 画面遷移（主要）

```
タブ: 記録 / チャート / 日記 / プロフィール / カレンダー（ホームタブなし）

記録トップ ─ 項目チップ（症状/排泄/食事/服薬/体重…横スクロール）→ 各入力（モーダル: キャンセル／保存）
          └ 保存 → 記録トップ＋保存完了トースト（取り消す）
          └ 保存失敗 → 入力画面にエラー表示（入力保持・再保存）
チャート ─ 血液検査 / 体重・食欲など（セグメント）→ 項目チップ → 原本の検査票 → 検査詳細
          └ 検査の記録 → 検査一覧 → 検査追加（手入力）/ 自動読み取り（将来）
日記 ─ 一覧（タグ絞り込み）→ 詳細 → 編集　／　＋ → 日記作成
プロフィール ─ 愛犬情報（編集する → 14 愛犬の登録・編集 → 犬種 › → 14b 犬種の選択）・病院・通院・薬 ／ 右上☰ → メニュー → 設定・ガイド・病院で見せる
カレンダー ─ 日付をタップ → 日付詳細（その日の記録・予定）→ 記録／予定を追加
```

## 5. 実装上の注意（要件の反映）

- 記録がない日は「異常なし」にしません。表示は「まだ記録がありません」です。
- チャートの扱い:
  - 未測定の値は 0 として描画しません。
  - 測定していない項目は、チップ自体を出しません。
  - 記録が2件以下のときは点を線で結びません。
- 検査値は、単位・基準範囲（検査票の記載どおり）・検査日・原本写真をセットで表示します。
- 自動読み取りは将来機能のバッジ付きです。現時点では手入力が前提です。
- 保存処理:
  - 保存が完了したらトーストを数秒表示し、「取り消す」を付けます。
  - 失敗したときは入力を保持し、理由と再試行の手段を表示します。
- ダークモード: トークンを差し替えるだけで切り替わる設計です（p31・p32 で確認用）。

**犬種別イラストはプロフィール写真ではありません。アプリ内に登場するキャラクターです。**

### プロフィール写真
- 飼い主が自由に設定します（カメラロールから選ぶ／撮影する／あとから変更）。
- 未設定のときは共通のプレースホルダー（ベージュの丸＋白い犬アイコン、登録画面はカメラアイコン）。犬種イラストは使いません。
- 表示箇所: 記録トップ・保存完了・ダーク版のヘッダー（44px）、チャート右上（36px）、プロフィール（100px＋カメラバッジ）、愛犬切り替えチップ（28px）、登録画面（96px）。

### 犬種との連動
- 現在選択中の愛犬の犬種でキャラクターを決めます。多頭飼いで愛犬を切り替えると、キャラクターも切り替わります。
- 対応表: `assets/dogs/dogs.json`（`imageRef`・`normal`／`happy`・`ready`）。共通素材: プードル 001・028・065・121 → 001、107 → 011。
- 専用イラストがない犬種（将来制作・未選択・ミックス・不明）: 制作済み（`ready: true`）からランダムに1つ選び、犬ごとに `fallbackBreedId` として保存して固定します。犬種名・犬種IDは変更しません。専用イラストが `ready: true` になったら自動で切り替えます。
- 表示ロジックは Expo 実装時に作成します。
