中身のフォルダ構成と index.html の位置

解凍したフォルダを開いて、次のような構成になっているか確認しましょう。

解凍したフォルダの中身（例）

  • lp （解凍してできたフォルダ）
    • index.html← トップページ
    • css （色・配置）
    • js （ボタンの動き）
    • images （写真）

これは説明用の例です

実際の納品データでは、フォルダ名や数が違うことがあります（例：img、assets など）。納品時の案内に書かれた構成を優先してください。

アップロードするもの

lpフォルダの「中身」すべて（index.html と各フォルダ）です。
lpフォルダそのものではありません。

サーバーに入れたあとの「正しい例」と「間違った例」

index.html が公開フォルダのすぐ下にないと、トップページが表示されないことがあります。

正しい例
  • {{OUTER}}
    • {{INNER}}
      • index.html
      • css
      • js
      • images

公開フォルダのすぐ下に index.html がある。

間違った例①
  • {{OUTER}}
    • {{INNER}}
      • lp← 1段深い
        • index.html
        • css / js / images

lpフォルダごと入れてしまった。トップページが表示されません。

間違った例②
  • {{OUTER}}
    • {{INNER}}
      • index.html
      • style.css← バラバラ
      • photo1.jpg

フォルダに入っていたファイルを外に出してしまった。デザイン崩れ・画像が出ない原因になります。

※「{{INNER}}」の部分には、実際の公開フォルダ名が入ります。{{INNERNOTE}}
