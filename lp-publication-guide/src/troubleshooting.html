確認するときの4つのお約束

  • もともとサーバーにあるファイル・フォルダは、削除・上書き・移動しない。
  • サーバーの設定（パーミッション、.htaccess、ネームサーバー、ドメイン設定の削除など）は自分で変えない。必要なときは公式サポートへ。
  • SSLなどの設定を何度もオン・オフしない（ConoHa WINGでは一定期間申請が制限されることがあります）。
  • パスワードは誰にも送らない。

1ホームページが表示されない
こんな状態に
なったら
真っ白／「このサイトにアクセスできません」／サーバー会社の初期ページが出る
まず確認
すること
  • URLの綴りが正しいか。https://ドメイン名/ の形で入力したか。
  • Xserver「このWEBスペースへは、まだホームページがアップロードされていません。」と出る → 公開フォルダ（ドメイン名/public_html）にLPが入っていない状態です（公式FAQ）。No.10 へ。
次に
試すこと
  • index.html が公開フォルダのすぐ下にあるか確認（本編「正しい例・間違った例」）。
  • ドメインの設定・変更直後は、時間をおいて再確認（Xserver反映に最大24時間程度／ConoHaネームサーバー変更は最大24〜72時間＝各公式）。
解決しな
ければ
サーバーやドメインの契約が切れていないか、契約先からのメールを確認。分からなければ契約先の公式サポートへ。
2「404」「Not Found」と表示される
こんな状態に
なったら
「404 Not Found」など、ページが見つからないという表示が出る
まず確認
すること
  • URLに誤りがないか（余計な文字、/lp/ などが付いていないか）。
  • ファイル名が半角小文字の index.html か（Index.html・index.html.html などになっていないか）。
次に
試すこと
  • ファイルがアップロードされているか、ファイルマネージャーで確認。
  • Xserver公式FAQでは「ネームサーバーが設定されていない」ことも原因に挙げられています。ドメインを他社で取った場合は設定状況を確認。
解決しな
ければ
ネームサーバーの変更は今のメール等に影響することがあるため、自分で触らず公式サポートか公開代行へ。
3「403」「Forbidden」と表示される
こんな状態に
なったら
「403 Forbidden」など、アクセスが禁止されているという表示が出る
まず確認
すること
  • 公開フォルダに index.html があるか。Xserver公式FAQでは、index.html などが無い場合に403になると案内されています。
  • lpフォルダごと入れて、index.html が1段深くなっていないか。
次に
試すこと
サーバーの利用期限が切れていないか（Xserver期限切れ等で凍結されると403になることがあります＝公式FAQ）。契約先からのメールを確認。
解決しな
ければ
パーミッション・.htaccess・アクセス制限・WAFなどの設定が原因のこともありますが、自分で変更せず公式サポートへご相談ください。
4画像が表示されない
こんな状態に
なったら
写真の場所が空白、×印、または代わりの文字が出る
まず確認
すること
  • images（納品時のフォルダ名）フォルダが公開フォルダの中にあり、中に写真が入っているか。
  • 写真をフォルダから出してバラバラに置いていないか（本編「間違った例②」）。
次に
試すこと
フォルダ名・ファイル名を自分で変更していないか、納品データと見比べる。大文字・小文字の違い（例：Photo.JPG と photo.jpg）でも表示されないことがあります。違っていたら、納品データのとおりにアップロードし直します。
解決しな
ければ
HTML内の画像の指定（パス）の問題の可能性があります（Xserver公式FAQ）。表示されない写真の場所をスクリーンショットして制作者へ。
5デザインが崩れる
こんな状態に
なったら
色がつかない、文字が左に寄って並ぶ、レイアウトがバラバラ
まず確認
すること
css フォルダが公開フォルダの中にあり、中にファイルが入っているか。css の中身だけを外に出していないか。
次に
試すこと
Ctrl＋F5（Mac：command＋shift＋R）で再読み込み。サーバー側の一時保存（キャッシュ）が残っていることもあるため、No.9 の方法も試します。
解決しな
ければ
崩れている画面のスクリーンショット（パソコン・スマホ）と公開URLを制作者へ送ってください。
6ボタンを押しても反応しない
こんな状態に
なったら
LINE・電話・予約などのボタンを押しても何も起きない／違う相手が開く
まず確認
すること
  • js フォルダが公開フォルダの中にあり、中にファイルが入っているか。
  • 電話・LINEボタンはスマートフォンで試す（パソコンでは動きが異なる場合があります）。
次に
試すこと
再読み込み（Ctrl＋F5）。スマホはブラウザのタブを閉じて開き直す。LINEアプリが入っているか確認。
解決しな
ければ
違うアカウント・番号が開く場合は、LP内のリンク先の問題です。サーバー設定では直りません。どのボタンで何が起きたかを制作者へ。
7HTTPS（https://）で開けない
こんな状態に
なったら
http:// では開けるが https:// ではエラー／「保護されていない通信」などと表示される
まず確認
すること
  • 無料SSLがオンか。ConoHaサイト管理→サイトセキュリティ→SSL→無料独自SSLの利用設定。XserverサーバーパネルSSL設定で「ON」か。
  • 設定した直後ではないか。Xserver反映まで最大1時間程度（公式）。
次に
試すこと
  • ConoHa無料独自SSLには、ドメインのネームサーバーがConoHaに設定されていることが必要です（公式）。
  • XserverSSL設定だけでは http→https に自動では切り替わりません（公式）。https:// 付きのURLで開ければ正常です。
解決しな
ければ
設定を何度もやり直さず、時間をおいて確認。それでもだめなら公式サポートへ。.htaccess での転送設定は自分で追加しないでください。
8ファイルをアップロードできない
こんな状態に
なったら
ボタンを押しても送れない、エラーが出る、途中で止まる
まず確認
すること
  • ログインが切れていないか。いったんファイルマネージャーを閉じて、もう一度ログインして開く。
  • 送ろうとしている場所が、公開フォルダ（No.10）になっているか。
次に
試すこと
  • ファイルを少しずつ（1フォルダずつ）送る。別のブラウザ（Chrome・Edge）でも試す。
  • Xserverログイン時の認証は、広告ブロッカー・VPN・古いブラウザ・JavaScript無効などで失敗することがあります（公式マニュアル）。
解決しな
ければ
表示されたエラーの文章をそのままメモ（またはスクリーンショット）して、公式サポートか公開代行へ。
9以前のページが表示される
こんな状態に
なったら
新しいLPを入れたのに、古いページや初期ページのまま変わらない
まず確認
すること
ブラウザの一時保存（キャッシュ）が原因のことがあります。Ctrl＋F5（Mac：command＋shift＋R）で再読み込み。スマホは別のブラウザやシークレット（プライベート）モードで開いてみる。Xserver公式FAQでもブラウザのキャッシュ削除が案内されています。
次に
試すこと
  • ConoHaコンテンツキャッシュは初期設定で「ON」です。サイト管理→高速化→ タブキャッシュ→コンテンツキャッシュの「キャッシュクリア」でクリアを押すと、一時保存が破棄されます（公式ガイド）。キャッシュの利用設定そのものは変えなくて大丈夫です。
  • Xserverサーバーキャッシュ設定がONの場合、ファイルは1〜2分間キャッシュされます（公式マニュアル）。数分待って再確認。
解決しな
ければ
本当に新しいファイルが入ったか、ファイルマネージャーで日時などを確認。index.html が別の場所に入っていないかも確認（No.10）。
10どのフォルダにアップロードするか分からない
こんな状態に
なったら
public_html やドメイン名のフォルダがたくさんあって、どこに入れればよいか分からない
まず確認
すること
ConoHaConoHa WING
public_html → ドメイン名 の中
Xserverエックスサーバー
ドメイン名 → public_html の中
順番が逆なので注意（各社公式FAQ）。
次に
試すこと
ドメインが複数ある場合は、公開URLのドメインと同じ名前のフォルダを選びます。例：https://konkatsu-xxxx.jp/ で公開 → konkatsu-xxxx.jp のフォルダ。
解決しな
ければ
分からないまま入れると、今のホームページを上書きしてしまうおそれがあります。作業を止めて、公式サポートか公開代行にご相談ください。

相談するときは

次の情報をそろえて相談すると、早く解決しやすくなります。

伝える情報

  • 契約しているサーバー（ConoHa WING／エックスサーバー）
  • 公開したいURL（例：https://example.jp/）
  • いつ・何をしたら・どうなったか
  • 表示されたエラーの文章、画面のスクリーンショット
  • このガイドの何番まで試したか

送ってはいけない情報

  • ログインパスワード、FTPパスワード
  • クレジットカード番号
  • SMSなどで届いた認証コード

スクリーンショットにパスワードなどが写っていないかも確認してください。
