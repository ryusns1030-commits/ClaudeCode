# 落合・中野周辺 現場系企業 営業リスト作成ツール

ホームページ制作の営業先を Google マップ（Places API）から自動で抽出します。

## 抽出条件（デフォルト）

| 項目 | 条件 |
|---|---|
| エリア | 落合周辺（落合駅・中井駅・上/中/下/西落合）半径1.5km、中野周辺（中野駅・中野坂上・東中野・新井）半径1.8km |
| 業種 | 製造（製作所・金属加工・板金・印刷など）、建設（工務店・内装・電気・設備・塗装・解体など）、運輸物流（運送・軽貨物・倉庫・引越し）、自動車整備・清掃など 計43キーワード |
| 評価 | ★5.0 |
| クチコミ数 | 5〜20件 |
| HP | なし / SNSのみ / 古い（コピーライト・更新日が10年以上前、スマホ非対応＋http のみ、Flash・frame など） |
| 連絡手段 | メールアドレス、またはファイル添付できる問い合わせフォームが見つかったところ |

## 使い方

1. Google Cloud で **Places API (New)** を有効にし、API キーを発行する
2. 実行する

```bash
pip install requests beautifulsoup4 openpyxl
export GOOGLE_MAPS_API_KEY=発行したキー
python3 sales_list/find_leads.py
```

`sales_list/output/leads_YYYYMMDD.xlsx` と `.csv` ができます。

- シート「営業リスト(メール・フォーム可)」：そのまま営業メールを送れる先
- シート「要手動確認」：条件には合うがメールが見つからなかった先（HPなし・SNSのみが中心）

### オプション

```bash
--min-reviews 3 --max-reviews 30   # クチコミ件数の範囲を変える
--min-rating 4.8                   # 評価条件を緩める
--old-years 8                      # 「古いHP」の年数基準を変える
--include-modern-sites             # 新しいHPを持つ会社も残す
```

## 注意

- 1回の実行で検索リクエストは最大約260回（2エリア × 43語 × 最大3ページ）。料金は Google の Places API の料金表で確認してください。
- 「古いHP」の判定は推定です。送る前にサイトを目で確認してください。
- 特定電子メール法により、営業メールには送信者の氏名・住所・配信停止の方法を書く必要があります。また、HPに「営業メールお断り」とある会社には送らないでください。
